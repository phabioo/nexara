# Nexara Nexus

Self-hosted dashboard for the home network: live monitoring, package management, services, power and an in-browser shell for Raspberry Pis (later Windows and macOS).

- Hub: `cmd/nexus` · Agent: `cmd/grid-agent`
- Concept: `docs/concept.md` · Decisions: `docs/decisions.md` · Design: `docs/design/DESIGN.md`
- Working rules for Claude Code: `CLAUDE.md`

Install (once released):

```
curl -fsSL https://github.com/phabioo/nexara/releases/latest/download/install.sh | sudo sh
```

Status: concept and design done, implementation of v0.1 not started.
